# 철벽 요새

굴에서 쏟아져 나오는 괴수 떼로부터 성문을 지키는 타워 디펜스 게임입니다.
설치할 것 없이 브라우저에서 바로 돌아갑니다. 그림과 효과음은 모두 코드로 그려 내고 만들어 내므로 이미지·음원 파일이 없습니다.

## 실행

`index.html` 을 브라우저로 열면 됩니다. 빌드 과정도, 의존 패키지도 없습니다.

GitHub Pages 로 올리려면 저장소 설정의 Pages 에서 이 브랜치의 루트를 고르면 됩니다.

## 하는 법

로비에서 **탑 뽑기**로 탑을 얻고, **탑 편성**에서 데려갈 탑 다섯을 고른 다음, **스테이지 선택**으로 들어가 스테이지를 하나씩 깨 나갑니다.

1. 스테이지는 열두 개입니다. 하나를 깨면 다음이 열리고, 스테이지마다 지도·적 구성·웨이브 수가 다릅니다.
2. 전투 화면 아래 가운데의 서랍에 편성한 탑이 놓입니다. 탑을 고르고 길가의 빈 땅을 눌러 세웁니다.
3. **시작**을 누르면 괴수 굴에서 적이 나옵니다. 적을 물리치면 골드를 얻습니다.
4. 세워 둔 탑을 누르면 강화(3단까지)하거나 팔 수 있고, 누구를 먼저 노릴지도 바꿀 수 있습니다. 강화할 때마다 건물 모양이 달라집니다.
5. 마지막 웨이브까지 막아내면 스테이지 클리어입니다. 남은 목숨에 따라 별을 받습니다: 2개 이하로 잃으면 ★★★, 9개 이하면 ★★, 그 밖은 ★.

웨이브가 시작되기 전에 세운 탑은 제값에 무를 수 있고, 한 번 싸움을 치른 뒤에는 들인 값의 70%를 돌려받습니다.
진행 상황과 별, 가진 탑과 보석은 브라우저에 저장됩니다. 하던 판은 로비의 **이어하기**로 이어서 할 수 있습니다.

### 뽑기와 편성

- 처음에는 석궁탑·대포탑과 보석 300개를 가지고 시작합니다. 스테이지를 처음 깨면 보석 100개, 새로 딴 별 하나마다 20개, 이미 깬 스테이지를 다시 깨면 10개를 받습니다.
- **탑 뽑기**는 한 번에 보석 100개(다섯 번에 450개)입니다. 등급별 확률은 일반 45% · 희귀 33% · 영웅 17% · 전설 4% · 신화 1%.
  처음 세 번은 반드시 새 탑이 나오고, 이미 가진 탑이 두 번 잇달아 나오면 그다음에는 새 탑이 나옵니다.
- 이미 가진 탑이 나오면 그 탑의 등급이 오릅니다(+5까지, 등급마다 위력 +8%). 등급이 가득 찬 탑은 보석 30개로 돌려받습니다.
- **탑 편성**에서 전투에 데려갈 탑을 다섯 개까지 고릅니다.

### 로비의 다른 메뉴

- **도전 모드** — 스테이지 5를 깨면 열립니다. 전장과 난이도를 골라 서른 웨이브를 버티고, 다 막아내면 무한 모드로 이어 갑니다. 다섯 웨이브마다 보석 15개를 받습니다.
- **도감** — 탑의 단계별 모습과 수치, 괴수의 특징을 볼 수 있습니다.

## 코드 구조

```
index.html             화면 뼈대
css/style.css          배치와 색
js/data.js             탑·적·지도·스테이지·뽑기 수치 (밸런스는 여기서 고칩니다)
js/sim.js              시뮬레이션. 화면 없이도 돌아갑니다
js/art/common.js       그림 규격, 공통 색과 도형·소품 도우미
js/art/tower-*.js      탑 그림 (탑마다 한 파일, 1~3단)
js/art/enemy-*.js      적 그림 (적마다 한 파일)
js/art/terrain.js      나무·바위·연못·괴수 굴·성문
js/art/ui.js           뽑기 화면의 보물 상자
js/render.js           캔버스 렌더러와 시각 효과
js/audio.js            효과음 합성
js/main.js             로비·스테이지 선택·뽑기·편성·도감 화면, 조작, 저장, 게임 루프
tools/art-preview.js   그림 점검판을 PNG 로 뽑기
tools/balance.js       봇이 게임을 끝까지 돌려 보는 밸런스 점검
tools/bundle.js        한 파일짜리 HTML 로 묶기
```

시뮬레이션은 언제나 가로 18×11 칸 좌표로 계산하고, 세로로 긴 화면에서는 렌더러가 가로·세로를 맞바꿔 그립니다.
전장 그림은 화면 전체를 덮고, 위의 상황판과 아래의 건설 서랍은 그 위에 얹힙니다. 지도는 둘 사이에 가장 크게 들어가도록 맞춰집니다.
탑과 나무는 칸보다 키가 크기 때문에, 렌더러가 화면 아래쪽에 있는 것이 위쪽을 가리도록 순서를 매겨 그립니다.

### 그림 고치기

그림은 "1 = 타일 한 칸" 좌표계에 캔버스 도형으로 그립니다. 규격은 `js/art/common.js` 맨 위 주석에 있습니다.
고친 뒤에는 점검판을 뽑아 확인합니다 (Playwright 와 Chromium 이 필요합니다).

```bash
node tools/art-preview.js tower cannon
```

```bash
node tools/art-preview.js enemy wolf
```

```bash
node tools/art-preview.js all
```

`dist/art/` 에 크게 본 그림과 실제 게임 크기 그림이 생기고, 칠해진 범위와 그리는 데 걸린 시간이 함께 출력됩니다.

### 밸런스 점검

```bash
node tools/balance.js --verbose
```

스테이지마다 세 가지 운영(골고루 섞기, 정해진 순서로 짓기, 석궁탑만 짓기)으로 끝까지 돌려 결과와 별점을 보여 줍니다.
스테이지의 웨이브나 수치를 바꿨다면 아래로 봇이 별 셋을 따는 한계 체력 배율을 다시 구해 `js/data.js` 의 `hp` 를 맞춥니다.

```bash
node tools/balance.js --tune
```

도전 모드(지도 × 난이도, 30 웨이브)는 `--challenge` 로, 편성에 따른 차이는 `--loadouts` 로 돌려 봅니다.

### 한 파일로 묶기

```bash
node tools/bundle.js
```

`dist/tower-defense.html` 하나에 모든 것이 담깁니다.
