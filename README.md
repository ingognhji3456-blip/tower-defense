# 철벽 요새

굴에서 쏟아져 나오는 괴수 떼로부터 성문을 지키는 타워 디펜스 게임입니다.
설치할 것 없이 브라우저에서 바로 돌아갑니다. 그림과 효과음은 모두 코드로 그려 내고 만들어 내므로 이미지·음원 파일이 없습니다.

## 실행

`index.html` 을 브라우저로 열면 됩니다. 빌드 과정도, 의존 패키지도 없습니다.

GitHub Pages 로 올리려면 저장소 설정의 Pages 에서 이 브랜치의 루트를 고르면 됩니다.

## 하는 법

1. 아래(넓은 화면에서는 오른쪽) 서랍에서 탑을 고르고, 길가의 빈 땅을 눌러 세웁니다.
2. **시작**을 누르면 괴수 굴에서 적이 나옵니다. 적을 물리치면 골드를 얻습니다.
3. 세워 둔 탑을 누르면 강화(3단까지)하거나 팔 수 있고, 누구를 먼저 노릴지도 바꿀 수 있습니다. 강화할 때마다 건물 모양이 달라집니다.
4. 서른 번째 웨이브의 화룡까지 막아내면 승리입니다. 그 뒤로는 무한 모드로 이어 갈 수 있습니다.

웨이브가 시작되기 전에 세운 탑은 제값에 무를 수 있고, 한 번 싸움을 치른 뒤에는 들인 값의 70%를 돌려받습니다.
진행 상황은 웨이브마다 브라우저에 저장되어, 다시 열면 이어서 할 수 있습니다.

### 탑

| 탑 | 값 | 특징 |
| --- | --- | --- |
| 석궁탑 | 50 | 빠른 연사. 값이 싸지만 단단한 껍질에는 약합니다. |
| 대포탑 | 110 | 포탄이 터지며 주변을 함께 때립니다. 떼로 올 때 강합니다. |
| 서리탑 | 80 | 냉기로 주변 적을 느리게 합니다. 3단이 되면 적이 받는 피해도 늘어납니다. |
| 로켓탑 | 170 | 먼 거리까지 로켓을 한꺼번에 쏟아붓습니다. |
| 번개탑 | 150 | 번개가 적에서 적으로 튑니다. 껍질과 회피를 무시합니다. |

### 적

| 적 | 특징 |
| --- | --- |
| 병정개미 | 약하지만 떼로 몰려옵니다. |
| 늑대 | 몹시 빠릅니다. |
| 장수풍뎅이 | 단단한 껍질이 약한 공격을 튕겨냅니다. |
| 말벌 | 날쌔게 날아 볼트·포탄 같은 물리 공격이 절반만 통합니다. |
| 대왕전갈 · 랩터 | 우두머리. 놓치면 목숨 다섯을 잃습니다. |
| 화룡 | 마지막 웨이브의 우두머리. 놓치면 그대로 패배합니다. |

### 단축키

| 키 | 동작 |
| --- | --- |
| `1`–`5` | 탑 고르기 |
| `Space` | 웨이브 시작 / 일시정지 |
| `P` | 일시정지 |
| `F` | 게임 속도 (1× · 2× · 3×) |
| `U` · `X` · `T` | 고른 탑 강화 · 판매 · 조준 바꾸기 |
| `Shift` + 클릭 | 같은 탑을 잇달아 세우기 |
| `Esc` · 오른쪽 클릭 | 취소 |

## 코드 구조

```
index.html             화면 뼈대
css/style.css          배치와 색
js/data.js             탑·적·웨이브·지도 수치 (밸런스는 여기서 고칩니다)
js/sim.js              시뮬레이션. 화면 없이도 돌아갑니다
js/art/common.js       그림 규격, 공통 색과 도형·소품 도우미
js/art/tower-*.js      탑 그림 (탑마다 한 파일, 1~3단)
js/art/enemy-*.js      적 그림 (적마다 한 파일)
js/art/terrain.js      나무·바위·연못·괴수 굴·성문
js/render.js           캔버스 렌더러와 시각 효과
js/audio.js            효과음 합성
js/main.js             조작, 메뉴, 저장, 게임 루프
tools/art-preview.js   그림 점검판을 PNG 로 뽑기
tools/balance.js       봇이 게임을 끝까지 돌려 보는 밸런스 점검
tools/bundle.js        한 파일짜리 HTML 로 묶기
```

시뮬레이션은 언제나 가로 16×10 칸 좌표로 계산하고, 세로로 긴 화면에서는 렌더러가 가로·세로를 맞바꿔 그립니다.
탑과 나무는 칸보다 키가 크기 때문에, 렌더러가 화면 아래쪽에 있는 것이 위쪽을 가리도록 순서를 매겨 그립니다.

### 그림 고치기

그림은 "1 = 타일 한 칸" 좌표계에 캔버스 도형으로 그립니다. 규격은 `js/art/common.js` 맨 위 주석에 있습니다.
고친 뒤에는 점검판을 뽑아 확인합니다 (Playwright 와 Chromium 이 필요합니다).

```bash
node tools/art-preview.js tower cannon
```

```bash
node tools/art-preview.js enemy wolf
```

```bash
node tools/art-preview.js all
```

`dist/art/` 에 크게 본 그림과 실제 게임 크기 그림이 생기고, 칠해진 범위와 그리는 데 걸린 시간이 함께 출력됩니다.

### 밸런스 점검

```bash
node tools/balance.js --verbose
```

지도·난이도마다 세 가지 운영(골고루 섞기, 정해진 순서로 짓기, 석궁탑만 짓기)으로 서른 웨이브를 돌려 결과를 보여 줍니다.
`js/data.js` 의 수치를 바꾼 뒤 돌려 보면 난이도가 어떻게 달라졌는지 바로 알 수 있습니다.

### 한 파일로 묶기

```bash
node tools/bundle.js
```

`dist/tower-defense.html` 하나에 모든 것이 담깁니다.
